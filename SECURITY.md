# Seguridad / Security

[Español: revisión 1.1.3](docs/SEGURIDAD-1.1.3.md) · [English: 1.1.3 review](docs/SECURITY-1.1.3.en.md)

Se recomienda instalar la última versión estable. Las versiones anteriores se conservan como historial y no reciben correcciones independientes. No publiques contraseñas, credenciales, certificados privados, documentos ni datos personales en incidencias públicas. Para comunicar una vulnerabilidad nueva, utiliza el informe privado de vulnerabilidades de GitHub si está habilitado; si no lo está, abre una incidencia sin detalles de explotación ni datos sensibles solicitando un canal privado.

Use the latest stable version. Older releases are historical snapshots and do not receive independent fixes. Never post passwords, credentials, private certificates, documents or personal data in public issues. Report new vulnerabilities through GitHub private vulnerability reporting when enabled. Otherwise, open an issue requesting a private contact channel without exploit details or sensitive data.

Atlas is designed for a trusted Mac account and private local networks. Do not expose its API directly to the Internet. Protect the Mac account, disk, backups and downloaded exports. Development builds are not notarized. Security checks reduce known risks; they do not guarantee absence of vulnerabilities in Atlas, models, runtimes or the operating system.
