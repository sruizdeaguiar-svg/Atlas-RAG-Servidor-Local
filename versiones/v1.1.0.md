Servidor RAG local para Apple Silicon, con aplicación macOS y cliente iPhone/iPad.

- Asistente inicial con detección de motores y almacenamiento externo.
- Gestión de llama.cpp, oMLX, vLLM y LM Studio; cambio de modelo y liberación de memoria.
- Navegador de carpetas, búsqueda, permisos y análisis estadístico con R.
- README con seis capturas e instrucciones de instalación.
- Código e IPA iOS sin firma en la carpeta ios/.

Validación: 45 pruebas de componentes y 30 comprobaciones de integración, además de las pruebas visuales y de motores reales documentadas. macOS 27 en Apple Silicon.

Los instaladores contienen una aplicación firmada para desarrollo y no están notarizados para distribución general. El PKG no lleva firma de instalador Developer ID. iOS requiere firma con una cuenta propia en Xcode. No se incluyen modelos, datos, credenciales ni perfiles personales.
