# Atlas RAG Local 1.1.4 · Contexto 65.536 y resultados R ampliados

[Publicación / Release](https://github.com/sruizdeaguiar-svg/Atlas-RAG-Servidor-Local/releases/tag/v1.1.4) · [Código / Source](https://github.com/sruizdeaguiar-svg/Atlas-RAG-Servidor-Local/tree/v1.1.4)

## Español

Corrige el HTTP 400 al interpretar resultados de R con IA local: el motor estaba cargado con un contexto de 4.096 tokens y recibía entradas mayores.

- Contexto predeterminado de 65.536 tokens en los selectores de motores del Mac y del iPad. Se muestra el contexto efectivo; los límites propios del modelo siguen aplicándose.
- Hasta 256 variables seleccionadas en R.
- Hasta 32 MiB de salida de R por ejecución, sin el recorte anterior a 200.000 caracteres y con aviso si se alcanza el límite. TXT y ZIP conservan los resultados.
- Interpretación de IA sin el recorte anterior a 20.000 caracteres; error específico si los datos exceden el contexto. Tiempo de espera local de 10 minutos.
- Idioma de interpretación español/inglés explícito y resultados tratados como datos, fuera de las instrucciones del sistema.
- La estimación de RAM sigue sin bloquear por defecto.

Validación: 70 pruebas aprobadas (R real con 25 variables y salida ficticia superior a 600.000 caracteres), 30 comprobaciones HTTP/HTTPS aisladas, y respuesta real de Qwen3.5 9B con contexto 65.536 en el iPad físico. Datos de prueba ficticios.

Se mantienen los controles de seguridad de 1.1.3. macOS: firma de desarrollo, sin notarización. iOS: paquete sin firma; requiere firma propia para instalar. El ZIP de código no incluye documentos cargados, base de datos, modelos ni credenciales.

[Notas detalladas](https://github.com/sruizdeaguiar-svg/Atlas-RAG-Servidor-Local/blob/main/docs/CAMBIOS-1.1.4.md) · [Seguridad](https://github.com/sruizdeaguiar-svg/Atlas-RAG-Servidor-Local/blob/main/SECURITY.md)

## English

Fixes local AI interpretation of R output by defaulting managed engines to 65,536 context tokens instead of 4,096. Supports 256 selected R variables and 32 MiB of R output per run, without silent result truncation. Context-specific errors, a 10-minute local inference timeout, explicit response language and untrusted result separation are included. Model capacity limits still apply; RAM estimates remain informational by default.

Validation: 70 automated tests, 30 isolated HTTP/HTTPS checks and a real Qwen3.5 9B response on the physical iPad with 65,536 context tokens. Only fictitious test data used. Security controls remain in place. Development-signed, non-notarized macOS installers; unsigned iOS package requires your own signing. Source archive excludes loaded data and secrets.

[Detailed English notes](https://github.com/sruizdeaguiar-svg/Atlas-RAG-Servidor-Local/blob/main/docs/CHANGES-1.1.4.en.md).
