# Atlas para iPhone y iPad

Cliente universal SwiftUI + WKWebView para acceder al servidor local Atlas del Mac.

- [Instalación, firma y conexión](INSTALL.md).
- [Proyecto Xcode](AtlasRAG.xcodeproj).
- [Código Swift](AtlasRAG/AtlasRAGApp.swift).
- [Paquete arm64 sin firmar](releases/AtlasRAG-iOS-unsigned.ipa).
- [Verificación SHA-256](releases/SHA256SUMS.txt).

El paquete sin firmar requiere tu propia firma de Apple para instalarse. No incluye perfiles ni credenciales personales. Código bajo Apache 2.0; los componentes de Apple mantienen sus condiciones originales.
